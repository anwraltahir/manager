# 💼 نظام إدارة أنور لإدارة المشاريع وعروض الأسعار والتسليم
### *Anwar Management - Project Lifecycle, Quotations & Handover System*

نظام إداري متكامل ومصمم خصيصاً للشركات البرمجية، الوكالات الرقمية، والمستقلين لإدارة دورة حياة مشاريع الويب والتطبيقات البرمجية من مرحلة العروض الأولية ونطاق العمل وحتى مرحلة التسليم النهائي (Handover) وإدارة بيانات الاعتماد والخوادم بأعلى معايير الأمان والاحترافية.

---

## ✨ المميزات الرئيسية (Key Features)

### 1. 📊 لوحة التحكم والإحصائيات الحية (Dashboard & Metrics)
- نظرة شاملة وفورية على جميع المشاريع ومراحلها (`قيد الانتظار`، `عروض الأسعار`، `قيد التنفيذ`، `المكتملة`).
- احتساب تلقائي للقيمة الإجمالية للمشاريع (Pipeline Value) ومعدلات الإنجاز.
- وصول سريع لأحدث المشاريع المنشأة مع إجراءات فورية (تعديل، تفاصيل، تصدير).

### 2. 📄 محرك عروض الأسعار وتوليد ملفات Word (DOCX Generator)
- تصميم احترافي متقدم متوافق مع الشركات والجهات الرسمية.
- تصدير فوري إلى مستند **Microsoft Word (.docx)** منسق بالكامل بـ:
  - غلاف رسمي مع شعار وبيانات الشركة والعميل.
  - جداول مالية مفصلة (نطاق العمل، الخدمات، الكميات، الأسعار الإجمالية، الخصومات، والرسوم الإضافية).
  - جدول مراحل التنفيذ واستحقاقات الدفعات (Payment Milestones).
  - شروط الدفع والضمان وسياسة التعديلات والدعم الفني.
  - دعم كامل للغة العربية (RTL) والإنجليزية (LTR).

### 3. 🎯 إدارة نطاق العمل والمراحل (Scope of Work & Milestones)
- إضافة وتعديل بنود نطاق العمل مع الأسعار والمدد الزمنية والكميات.
- قوالب جاهزة سريعة للإضافة بنقرة واحدة (تصميم واجهات UI/UX، برمجة الواجهات الأمامية، بناء الـ API، الربط مع بوابات الدفع، إعداد السيرفرات، إلخ).
- تقسيم مرن للمشروع إلى مراحل تنفيذية مرتبطة بنسب مئوية أو مبالغ استحقاق.

### 4. 🔐 وثيقة تسليم المشروع وخزينة البيانات الحساسة (Handover & Credentials Vault)
- إنشاء وثيقة تسليم نهائية احترافية وشاملة (Handover Document) تتضمن:
  - تفاصيل الاستضافة، النطاق (Domain)، وبيانات خوادم DNS.
  - بيانات الوصول للوحات التحكم، قواعد البيانات، ومستودعات الأكواد (GitHub / GitLab).
  - مفاتيح الـ API وخدمات الطرف الثالث (Third-Party Integrations).
  - بنود التسليم، الفحص الفني، والضمان.
- **خزينة بيانات مشفرة في الواجهة**: إمكانية إخفاء/إظهار كلمات المرور ونسخها بنقرة واحدة بأمان.

### 5. 👥 دليل العملاء (Clients CRM)
- قاعدة بيانات شاملة للعملاء والشركات ومعلومات الاتصال والعناوين.
- ربط المشاريع مباشرة بالعملاء الحاليين أو إنشاء عميل جديد تلقائياً أثناء صياغة المشروع.

### 6. ⚙️ الحقول المخصصة الديناميكية (Dynamic Custom Fields)
- محرك حقول مرن يتيح إضافة حقول إضافية للمشاريع حسب متطلبات كل عمل:
  - نصوص عادية ونصوص طويلة (Text / Textarea).
  - أرقام وقيم مالية (Numbers / Currency).
  - تواريخ وقوائم خيارات منسدلة (Dates / Selects).
  - حقول بيانات سرية (Password / Secret Key Fields).

### 7. 💾 النسخ الاحتياطي واستعادة البيانات (Backup & JSON Sync)
- تصدير كامل لقاعدة بيانات المشاريع والعملاء والإعدادات إلى ملف `JSON`.
- استيراد سريع للبيانات للنسخ الاحتياطي أو النقل بين الأجهزة.
- إمكانية إعادة ضبط النظام إلى البيانات التجريبية الافتراضية بنقرة واحدة.

### 8. 🌐 الدعم الكامل للغتين (العربية والإنجليزية)
- تبديل سلس ولحظي بين اللغة العربية (RTL) والإنجليزية (LTR).
- قوالب عروض أسعار متوافقة مع متطلبات السوق الخليجي والعربي والدولي.

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend**:
  - **React 19** مع **TypeScript** لبناء واجهات مستخدم تفاعلية وعالية الأداء.
  - **Vite 6** كبيئة بناء سريعة ومُحسّنة.
  - **Tailwind CSS v4** مع تصميم **High Density** مدمج ومريح للعين.
  - **Motion** للتأثيرات الانتقالية الحركية السلسة.
  - **Lucide Icons** لمجموعة الأيقونات العصرية.
  - **docx**: مكتبة توليد مستندات Word النقية مع التنسيقات والجداول المخصصة.

- **Backend**:
  - **Node.js** & **Express** لبناء خادم Full-stack قوي ومرن.
  - **tsx** لتشغيل خادم TypeScript في وضع التطوير.
  - **esbuild** لتجميع خادم الإنتاج بسرعة فائقة داخل حزمة موحدة (`dist/server.cjs`).
  - مسارات API مدمجة للفحص الصحي (`/api/health`)، معلومات النظام (`/api/system-info`)، والمزامنة السحابية للنسخ الاحتياطي (`/api/backup`).

## 🚀 طريقة التثبيت والتشغيل (Getting Started)

### المتطلبات المسبقة:
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).
- مدير الحزم `npm` أو `pnpm` أو `bun`.

### 1. تثبيت الحزم (Install Dependencies)
```bash
npm install
```

### 2. تشغيل النظام في وضع التطوير (Development Mode)
```bash
npm run dev
```
سيعمل التطبيق على الرابط المحلي: `http://localhost:3000`

### 3. بناء المشروع للإنتاج (Production Build)
```bash
npm run build
```
يقوم هذا الأمر ببناء الواجهة الأمامية عبر Vite وتجميع خادم الـ Express عبر `esbuild` في مجلد `dist/`.

### 4. تشغيل خادم الإنتاج (Start Production Server)
```bash
npm start
```
